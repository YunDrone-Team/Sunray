# 简易避障算法使用说明

## 功能介绍

本算法实现了一个简单的无人机避障飞行功能，具有以下特点：

- **输入数据**：使用立体视觉里程计(`/baton/stereo3/odometry`)和深度图像(`/baton/depth_image`)
- **控制方式**：采用XyVelZPosYawrate模式，只允许前进和转向，不支持后退和侧向飞行
- **避障逻辑**：检测到前方障碍物时会转向，前方畅通时朝目标点前进
- **动态目标**：支持飞行过程中动态更新目标点

```bash

```

### 2. 自定义参数启动

```bash
roslaunch sunray_tutorial simple_obstacle_avoidance.launch \
    uav_id:=1 \
    flight_height:=1.2 \
    forward_vel:=0.6 \
    safety_distance:=2.0 \

    target_y:=2.0
```

```bash
rosrun sunray_tutorial simple_obstacle_avoidance \
    _uav_id:=1 \

    _target_y:=0.0
```

## 参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `uav_id` | int | 1 | 无人机ID |
| `uav_name` | string | "uav" | 无人机名称 |
| `flight_height` | double | 1.0 | 飞行高度(米) |
| `forward_vel` | double | 0.5 | 前进速度(m/s) |
| `rotate_speed` | double | 0.3 | 转向速度(rad/s) |
| `safety_distance` | double | 1.5 | 安全距离(米) |
| `target_x` | double | 3.0 | 初始目标X坐标 |
| `target_y` | double | 0.0 | 初始目标Y坐标 |
| `target_topic_name` | string | "/target_pos" | 动态目标话题名 |

## 动态目标更新

### 发布新的目标点

```bash
# 发布一个新目标点到坐标(5, 3)
rostopic pub /target_pos geometry_msgs/PoseStamped "
header:
  frame_id: ''
pose:
  position:
    x: 5.0
    y: 3.0
    z: 0.0
  orientation:
    x: 0.0
    y: 0.0
    z: 0.0
    w: 1.0"
```

### 使用Python脚本动态设置目标

```python
#!/usr/bin/env python
import rospy
from geometry_msgs.msg import PoseStamped

def send_target(x, y):
    pub = rospy.Publisher('/target_pos', PoseStamped, queue_size=1)
    rospy.init_node('target_sender')
    
    msg = PoseStamped()
    msg.header.frame_id = ""
    msg.pose.position.x = x
    msg.pose.position.y = y
    msg.pose.position.z = 0.0
    msg.pose.orientation.w = 1.0
    
    rospy.sleep(1)  # 等待发布者初始化
    pub.publish(msg)
    print(f"发送目标点: ({x}, {y})")

if __name__ == '__main__':
    send_target(5.0, 2.0)
```

## 算法逻辑

### 1. 深度图像处理
- 将深度图像分为左、中、右三个区域
- 计算每个区域的平均深度值
- 根据安全距离判断是否有障碍物

### 2. 避障策略
- **前方有障碍**：停止前进，根据左右区域情况选择转向方向
  - 左边畅通：向左转
  - 右边畅通：向右转  
  - 两边都畅通：默认向右转
  - 三面都有障碍：原地转向寻找出路

- **前方畅通**：
  - 如果朝向目标：前进
  - 如果未朝向目标：转向目标方向

### 3. 飞行状态
- **导航中**：朝目标点飞行，遇障碍物时避障
- **到达目标**：悬停等待新目标
- **避障中**：转向寻找安全通道

## 话题接口

### 订阅话题
- `/uav1/sunray/uav_state` - 无人机状态
- `/baton/stereo3/odometry` - 立体视觉里程计
- `/baton/depth_image` - 深度图像
- `/target_pos` - 动态目标点更新

### 发布话题
- `/uav1/sunray/uav_control_cmd` - 无人机控制命令
- `/uav1/sunray/setup` - 无人机设置命令

## 注意事项

1. **飞行限制**：只支持前进和转向，不支持后退和侧向移动
2. **传感器依赖**：需要深度相机和视觉里程计正常工作
3. **安全距离**：建议根据飞行环境调整`safety_distance`参数
4. **飞行速度**：建议在测试阶段使用较低的`forward_vel`和`rotate_speed`

## 故障排除

1. **无人机不连接**：检查MAVROS连接和PX4状态
2. **没有深度数据**：检查深度相机是否正常发布数据
3. **避障不生效**：检查深度图像质量和安全距离设置
4. **目标更新无效**：检查话题名称是否正确
