Sunray Open Source UAV/UGV Platform

Sunray 用户二次开发手册

本手册面向有一点 ROS 基础、但没有系统接触过 PX4 的学生。目标不是让你一开始读懂每一行飞控代码，而是让你理解 Sunray 的分层、话题接口和常见改法，能够稳妥地把自己的算法接进无人机或无人车任务。

核心入口`sunray_common`、`sunray_uav_control`、`sunray_tutorial`、`sunray_planner_utils`、EGO
推荐改法复制示例任务，发布 Sunray 控制话题，少改底层控制节点
外部项目EGO、FUEL、VINS、雷达驱动、轮趣底盘等以接入边界为主
文档范围只维护 `docs/`，不修改任何源码、配置或脚本
